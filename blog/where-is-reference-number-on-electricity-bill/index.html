Quick answer

Where is reference number on bill?

Start in the consumer-detail block. This block normally holds your name, address, Customer ID and connection details. The reference number sits nearby on many PITC-format bills.

Search for the words REFERENCE NO before you read any number. The side of the page matters far less than the printed label. LESCO and IESCO may use different placement.

Do not assume the longest number is always correct. Some bills show several long numbers close together. Read each label slowly.

The exact search “where is reference number on bill” needs a visual answer, not a corner guess.

Once the correct field is clear, open the free bill checker and enter the required number.

Label first

Start with the label, not the corner

Many online guides give one simple corner answer. Some say top-left. Others say top-right. Both can fail after a bill design revision.

Use the printed label as your anchor. Scan the customer area for REFERENCE NO or a short REF NO label. Then copy the value beside or under the same label row.

One layout can put the reference field above Customer ID. Another layout may place it directly beside Customer ID in a wider customer box. Read the words around each digit string before the copy.

Always check the newest printed bill or downloaded duplicate PDF first. An older bill may come from an older connection state or an older account revision. A revised layout can also change the field position.

Keep this habit. A corner rule gives a quick hint only. A label rule works after a layout update.

Tip: Check the newest bill before an old phone photo. A clear current print gives the safest value.

Number format

What does the reference number look like?

Many PITC DISCO bills show 14 digits in small groups. Spaces can separate the groups. A U or R may sit beside the last digit.

A masked print can look like this.

XX XXXXX XXXXXXX U

Count the digits separately from any U or R. The example pattern has fourteen digits before the suffix.

Use digits only in a 14-digit digit-only field. Do not copy spaces. Do not add U or R there either.

Follow the selected official page closely. A different company page can ask for letters or a different identifier. Do not carry a suffix rule from one page into another page.

The number may be split over one or two lines on a paper copy. Write it into a note in four-digit parts. Then remove spaces before entry.

A bold font can make the field easier to find. A faint print can do the opposite. Use a phone camera zoom only for reading the faded text.

Do not copy from memory. Long digit strings are easy to misread. Verify the last three digits against the paper before typing.

A page can show one number near the company name and another number near the customer block. Read the label next to each value. The label decides the field.

Field comparison

Reference number, Customer ID and other nearby fields

The biggest wrong number is usually Customer ID. It can sit very close to REFERENCE NO. A quick copy can pull the lower row instead of the top row.

The order can vary. Some bills put Customer ID under the reference value. Others place it beside the reference value. Read the label on each field.

Think in field pairs. Pick Reference No for a reference lookup. Pick Customer ID for a customer lookup. Never move one value into the other field to test it.

Need the field choice first? Match the printed label to the selected field before copying another value.

A meter number can still matter during an official account-support discussion. It never replaces the main online lookup. Bill month tells the period, not the account identifier.

Bill number can look official. It still points to a statement version or print record. Skip it for the online reference field.

Do not post a full bill screenshot to recover the account. The bill contains connection and identity details. A private record is safer.

PITC DISCO route

Find the reference number on your PITC DISCO bill

PITC serves the public duplicate-bill flow for many DISCOs. The official PITC bill portal is the main online route named by the Power Division.

Start with the consumer area. Find REFERENCE NO and keep the nearby CUSTOMER ID separate. Then choose the matching field on the online page.

Use this copy path.

  1. Confirm the company name from the bill header.
  2. Open the consumer-detail block.
  3. Find REFERENCE NO on the printed label.
  4. Copy the value without its spaces.
  5. Keep U or R out of a 14-digit digit-only input.
  6. Check the field list before Send or Check.

A company revision may shift the visual order. The same label rule still works. The question “where is reference number on bill” deserves one label-first answer.

LESCO

Find REFERENCE NO near the customer details on the newest LESCO bill. The official LESCO bill page also shows Reference No and Customer ID as different options.

Use each value only in its own field. The LESCO bill checker sends you toward the official route.

IESCO

IESCO bills may present REFERENCE NO and CONSUMER ID as clearly separate account fields. Use the reference value only in a Reference No field. Keep the consumer value for a supported Customer ID flow.

Read the newest paper bill or downloaded duplicate first. A reused phone screenshot can hide the company header.

The IESCO bill checker follows the official public route.

MEPCO and other PITC DISCOs

Use the same label-first rule for MEPCO, FESCO, PESCO and similar PITC-format bills. Find REFERENCE NO first. Do not use the meter number for the reference field.

The customer area may also carry tariff, load or feeder details. Those details describe the supply record. Do not copy them into the lookup box.

You can open the MEPCO checker after the label check.

Common clue: The reference value may have fourteen grouped digits on many PITC-format pages. Customer details and tariff text sit around it. The final answer still comes from the printed label.

K-Electric route

K-Electric uses a 13-digit account number

K-Electric follows a separate route. Do not use a PITC Reference No pattern for a KE bill.

Look for the 13-digit K-Electric account number on the account area of the KE bill. Official KE billing pages ask for this account number. The KE bill design may also show it with its own label.

Check the exact number beside the account label. Ignore the bill month and payable amount for the lookup. Do not copy a customer support code from another app message.

Use the K-Electric bill page or go to the official K-Electric digital bills page. The official Know Your Bill guide also explains the KE bill layout.

Do not apply the PITC U/R suffix rule to KE. KE uses its own account format and its own digital services.

Missing number

What to do with a missing number

Start with a clean search through one place at a time. This avoids a rushed guess.

Check the newest paper bill from this account first. Hold it under normal room light. Faded ink often looks clearer at an angle.

Check the latest bill PDF from your email or official service. Zoom into the consumer-detail area. A blurry paper copy may hide one digit.

Check an old paid-bill receipt. Many receipts print a reference or account field. Match the company name before using it.

Check your bank or wallet payment history. Search for electricity, power or the exact company name in the app. Copy the full saved reference from the entry.

Ask the account holder. A landlord, family member or resident may keep the latest clean bill.

Look at your saved payment notifications too. A bank app can keep the old bill reference in its list. Verify the sender and company before reuse.

Use Customer ID only through a matching official option. Never put it into a Reference No box by default.

Do not buy a claimed number lookup from a stranger. The bill reference belongs to a private account record and can expose activity. Official help is the safer route for a lost bill.

Not accepted

Number not accepted? Recheck these parts

Recheck the company name before every retry. A number from one DISCO will not open another DISCO's bill.

Recheck the selected field on the official form before typing again. Customer ID belongs in Customer ID. REFERENCE NO belongs in Reference No.

Remove spaces from a digit-only input. Do not add the U or R suffix to a 14-digit digit-only field.

Count leading zeros. Mobile keyboards can skip one zero during a fast copy. A visual group check makes the error easier to spot.

Use the newest printed bill after a connection change. An account correction, transfer or meter replacement can make an older value fail.

Try the official company route directly. A third-party shortcut can hide a portal issue.

Open the bill in another browser after one careful retry. This can show a temporary page or input problem without changing your number.

Retry slowly once. Then move to the full not-found guide. Random repetition rarely fixes a field or account mismatch.

Safe use

Copy and use the number safely

Write the number in short groups. Read each group aloud or point to it once. This reduces a missed zero.

Keep the copied value away from public notes apps. Use a personal note instead of a shared family chat. Remove it after the bill opens.

Keep a private photo with the consumer details covered. Blur the name, address, Customer ID and full reference number before sharing a bill image.

Do not post the full number in a public comment. It can identify the account and expose private bill details.

Confirm the consumer name, company and bill month after the bill opens. Then compare the due date and payable amount. A guessed amount can be wrong.

Use the official portal or a trusted bank and wallet route for payment. The guide on how to pay your electricity bill online covers the safe next step.

Avoid mistakes

Common mistakes

These errors create most failed lookups. Many “where is reference number on bill” searches begin with one of these copies.

  • Trust one fixed corner without reading the label.
  • Copy Customer ID into a Reference No field.
  • Use the meter number as the account reference.
  • Treat BILL NO as the long-term connection value.
  • Type spaces into a digit-only form.
  • Add U or R into a 14-digit digit-only box.
  • Use an old number after a correction or connection transfer.
  • Follow a PITC route for a K-Electric account.
  • Read a faded last digit from an old blurry photo.
  • Share a complete bill screenshot on social media.
  • Assume the bill amount from last month is still correct.

One careful label check fixes the first three errors. Slow digit entry fixes most of the rest.

A duplicate bill can show the same number in another layout. Use the newest visible copy for the cleanest comparison.

Quick answers

Frequently asked questions

Where is the reference number on a LESCO bill?

Find the REFERENCE NO label near the customer details on the newest bill. Do not trust one corner alone. Compare each nearby field name. Copy only the digits the selected official field asks for. Keep Customer ID separate.

Is Customer ID the same as a reference number?

No. Official pages can show Reference No and Customer ID as separate options. Use Customer ID only in its official matching field. Do not place it into the Reference No box. Recheck the label above or beside the digits before you copy anything.

Can I check my bill with the meter number?

Do not use a meter number as the main reference route. It can relate to the meter or another supply record. Use Reference No in its named field. Use supported Customer ID only inside its own field.

Do I copy U or R with the reference number?

Usually no on a 14-digit digit-only form. Copy digits and remove suffix letters. Follow the selected official page for any other format. The printed field label remains more useful than a corner shortcut.

What number does K-Electric use?

K-Electric uses its 13-digit account number. This route differs from the PITC DISCO reference flow. Look for the account number on the newest KE bill. Then use a KE digital service.

Why is my printed reference number not found online?

The company name or selected field may still be wrong on the form. The value may also belong to an older connection state. A current record may need normal posting time. Count the digits on the newest bill. Then use the full not-found recovery guide after clean checks.

Final step

Final step

The answer to “where is reference number on bill” is simple. Find the exact label. Read the adjacent number. Copy only what the active form asks.

For most PITC DISCO bills, this means REFERENCE NO and fourteen digits. For K-Electric, use its 13-digit account number. Once the number is clear, open the free bill checker and check the newest bill.
