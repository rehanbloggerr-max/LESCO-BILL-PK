# BijleeBill.pk Static Website

Optimized static production files for GitHub Pages and Cloudflare Pages.

## Structure
- `index.html` — entry page
- `styles.css` — compiled stylesheet
- `assets/` — JavaScript bundle
- `images/` — optimized WebP images

## Deploy
Upload the contents of this folder to the repository root. No build command is required.

All paths are relative for GitHub Pages project URLs and Cloudflare Pages.

## Bill URLs
- Reference number: `/general?refno=...`
- Customer ID: `/general?appno=...`
- LESCO Customer ID uses the official LESCO POST flow.
